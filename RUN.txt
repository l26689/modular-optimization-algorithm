================================================================================
  MOA（Modular Optimization Algorithm）—— 运行指南
  用于会展评委现场操作
================================================================================

【项目简介】
MOA 是一个模块化优化算法框架，支持粒子群(PSO)、差分进化(DE)、遗传算法(GA)
等多种算法的自由组装。本作品的核心亮点是"元优化"——用算法搜索最优算法组合：
在 Web 界面中选择目标问题，系统自动搜索最优的(算法+参数)并返回结果。

================================================================================
  一、环境要求
================================================================================

  - JDK 17 或更高版本（推荐 Eclipse Temurin 17+）
  - Maven 3.8+（用于编译）
  - 操作系统：Windows / macOS / Linux 均可

================================================================================
  二、编译项目（首次使用，约 10 秒）
================================================================================

  打开终端，进入项目根目录，执行：

    mvn compile -q

  编译成功后会生成 target/classes 目录，无任何输出即为成功。

================================================================================
  三、启动 Web 探索页面
================================================================================

  执行以下命令启动服务：

    java -cp target/classes moa.example.meta.server.WebServer

  启动后终端会显示：

    元优化界面已启动：http://127.0.0.1:8080

  在浏览器中打开上述地址即可进入操作界面。

  （如需更改端口：java ... WebServer 9090）

================================================================================
  四、Web 页面操作流程
================================================================================

  页面分为三个步骤区域：

  第1步 - 选择目标问题
    ┌─ 预设问题 ─────────────────────────────┐
    │ 下拉菜单可选：                        │
    │   Sphere（单峰，最简单）              │
    │   Rosenbrock（香蕉函数，难优化）      │
    │   Rastrigin（大量局部最优）           │
    │   Ackley（陡峭全局盆地）              │
    │   Griewank（周期性多峰）              │
    │   CountingProblem（为元优化的内部包装）│
    │                                       │
    │ 维度：默认 10，可直接修改             │
    └───────────────────────────────────────┘

  第2步 - 选择算法与参数范围
    勾选想要搜索的算法（PSO 粒子群 / GA 遗传 / DE 差分进化），
    设置各参数的最小值/最大值（已有合理默认值，可直接使用）。

  第3步 - 元搜索设置
    ┌──────────────────────────────────┐
    │  外层轮数：  100  （默认）      │
    │  内层预算：  2000 （默认）      │
    │  粒子数：    50   （默认）      │
    │                                │
    │  [开始搜索]                     │
    └──────────────────────────────────┘

  点击"开始搜索"后等待片刻，下方会显示结果表格：
    - 排名：从优到劣
    - 算法：PSO / GA / DE
    - 最佳参数值
    - 对应的问题函数值

  注：元搜索本质上是用 PSO 在外层搜索参数空间，每评估一组参数就需要
      跑一次完整的内层优化。因此较大参数（如 100 轮 x 50 粒子）需要
      等待数十秒到数分钟。当前版本可在终端看到进度输出：

      [元搜索] 已测试 10 个不同配置，当前得分 0.0123

================================================================================
  五、可选：命令行对比实验
================================================================================

  我们提供了一个对比实验脚本，将元搜索发现的参数与网格穷举、学界经典
  参数在 Ackley 10D 问题上做正面交锋：

    java -cp target/classes moa.example.AckleyPSOComparison

  该脚本会：
    1. 网格穷举 27 种参数组合（w x c1 x c2 = 3 x 3 x 3）
    2. 选出最佳组合作为"手工调优基准"
    3. 与元搜索、学界基准各跑 50 轮对比
    4. 输出胜负统计和均值/标准差

  预期输出示例：
    元搜索   (w=0.635 c1=2.5 c2=1.231):  均值=0.000016
    网格最佳  (w=0.7 c1=2.0 c2=1.0):      均值=0.000000
    学界基准  (w=0.73 c1=c2=1.49):         均值=0.002275

================================================================================
  六、关闭服务
================================================================================

  在终端按 Ctrl + C 即可停止 Web 服务器。

================================================================================
  七、项目结构速览
================================================================================

  moa/
  ├── framework/         核心抽象（Problem、Component、State、Engine）
  ├── components/        通用组件（记录器、终止条件）
  ├── algorithm/         PSO / GA / DE 算法实现
  │   ├── pso/          粒子群优化
  │   ├── ga/           遗传算法
  │   └── de/           差分进化
  ├── problem/           目标问题实现（连续函数）
  └── example/
      ├── meta/          元优化核心（ParameterSpaceProblem 等）
      └── meta/server/   当前 Web 服务（WebServer）
  web/                   前端页面（HTML+CSS+JS）-> 已打包到 resources
